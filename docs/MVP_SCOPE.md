# Границы MVP 0.1

Дата: 13.10.2026. MVP реализует рабочий цикл графика ПИР. Полный объём PRD и TechPlan остаётся целевым планом развития.

| Область | Реализация MVP | Следующий шаг полного продукта |
| --- | --- | --- |
| Хранение графа | Неизменяемый JSON-снимок внутри реляционной Revision; пользователи, объекты, версии, факты, аудит и отчёты — отдельные таблицы | Нормализованные участия, интервалы, передачи и зависимости для большого портфеля |

| Передачи | Нулевое событие, специальность, получатель, входящие зависимости | Групповые передачи нескольких отправителей/получателей и внешние связи между графиками |

| Масштаб | Локальный пилот и небольшие наборы данных | Индексы/проекции/пагинация и нагрузочный прогон на 100 000 графиков / 100 пользователей |

## Достоверность исходных данных

Учебные схемы `DEMO-23-2` и `20-1 / DEMO` созданы для проверки приложения. Они не объявляются нормативным восстановлением сетевой модели. Карточки исходных моделей без полной структуры не доступны для автоматического создания сети.

Начальный календарь — учебная пятидневка без утверждённого списка праздников. Пользователь с ролью координации или технического директора может создать версию календаря с официальными исключениями и источником. Новая версия применяется в черновике и не изменяет предыдущие планы.

Проценты исходного изображения не использованы как нормативы длительности или стоимости.

## Следующие приоритеты

1. Проверить с заказчиком основной рабочий цикл на 2–3 реальных графиках и утвердить правила печатной формы.
2. Подготовить реальные сетевые модели, отделы, сотрудников и календарь.
3. Добавить управление пользователями и MFA перед внешним доступом.
4. Реализовать многомодельные и межграфиковые сети, остаточный прогноз и полноценную загрузку по периодам.
5. Ввести фоновые импорты/выгрузки, остальные отчёты и нагрузочную проверку.

Сокращения не меняют исходные требования молча: PRD и TechPlan сохранены, а данная таблица фиксирует фактическую границу первой работающей версии.
