# Протокол проверки MVP 0.1

Дата финальной проверки: 13.10.2026, Asia/Tashkent.

## Результаты

| Проверка | Результат |
| --- | --- |
| TypeScript и production-сборка Vite (`npm run build`) | Успешно |
| Django с настоящим PostgreSQL (`manage.py test pir`) | 23 теста, все прошли |
| Сборка Docker API и web | Успешно; Python 3.13, Node 24, PostgreSQL 18 |
| Миграции в базе локального пилота | Применены, включая защитный триггер версий |
| Chrome: проверка через `http://localhost:8088` | 1 браузерный тест прошёл |
| Chrome: полный рабочий цикл в отдельной базе разработки | 1 браузерный тест прошёл при предыдущей проверке реализации |

Серверные тесты проверяют CPM, FS/SS/FF, циклы, календарные исключения, события начала/конца дня, отрицательный резерв, суммы, области доступа, назначенного утверждающего, новые редакции, конфликт изменения, факт и исторические отчёты. Отдельно проверены сокрытие стоимости чужого отдела, неизменность снимка отчёта, CSRF, защита содержимого утверждённой версии непосредственно в PostgreSQL, безопасная текстовая запись в Excel и импорт без записи до подтверждения пользователем.

Финальный браузерный тест проверил вход ГИПа, обзор, открытие собственного Ганта с семью работами и связями, скачивание XLSX, отчёт по специальностям и экран шириной 390 px. Необработанных ошибок JavaScript не обнаружено. Скриншоты [обзора](./dashboard.png), [Ганта](./gantt.png) и [мобильного экрана](./mobile.png) сняты с Docker-сборки и просмотрены визуально.

Рабочий цикл проверен в базе разработки: ГИП создаёт индивидуальный график, добавляет работу, сохраняет и отправляет; технический директор утверждает; координатор фиксирует 100% выполнения и сохраняет снимок отчёта. Этот тест создаёт график `E2E-…`, поэтому его не запускали повторно в чистом учебном портфеле Docker.

## Воспроизведение

```bash
# Нужен запущенный PostgreSQL разработки, как описано в README.
.venv/bin/python apps/api/manage.py test pir
cd apps/web
npm run build
PIR_TEST_URL=http://localhost:8088 npm run test:e2e -- tests/smoke.spec.ts
# Полный рабочий цикл: запущенные dev-серверы и отдельная учебная база.
npm run test:e2e -- tests/workflow.spec.ts
```

## Ограничения проверки

Нагрузочная проверка большого портфеля, аудит безопасности, восстановление из резервной копии и размещение на внешнем сервере не выполнялись. Автотесты не подтверждают нормативную корректность учебных сетевых моделей и календаря праздников. Фактический объём первой версии указан в [MVP_SCOPE.md](../MVP_SCOPE.md).
